# Artemiz Android builds

- `release/CherryTree-Modded.xapk` — ARM64 build.
- `release/Artemiz-Android32.xapk` — ARMv7 32-bit build.

Both XAPK bundles contain the Artemiz base APK and matching split APKs. Use an installer that supports XAPK packages.

## Weather cycle

The local cycle has eight fixed three-minute slots. Each event lasts two minutes, followed by one calm minute. Astral Surge rolls a stable 2×–5× multiplier for XP across all skills. Verdant Bloom halves crop grow time; Fortune Squall doubles monster drop thresholds up to 100%; Harvest Tide doubles Fishing, Forestry, and Mining yields; Artisan Ember doubles Cooking, Crafting, Firemaking, Fletching, and Alchemy outputs; Shadowveil doubles Thieving loot; Explorer's Aurora doubles Discovery rewards; Warfront gives +50% combat damage, +25% player attack speed, and −25% incoming damage. Each event has its own in-game style icon.
